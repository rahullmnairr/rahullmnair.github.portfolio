# Rahul M Nair – Portfolio

Single-page portfolio built with HTML, CSS and JavaScript. No build step needed.

## Publish with GitHub Pages
1. Create a public repository (for example `portfolio`).
2. Upload every file in this folder to the repository root.
3. Open Settings > Pages, choose "Deploy from a branch", select `main` and `/ (root)`, then save.
4. The site goes live at https://rahullmnairr.github.io/portfolio/

## Files
- `index.html` – the whole site (photo is embedded)
- `photo-cutout.png` – transparent portrait, kept as a spare
- `.nojekyll` – tells GitHub Pages to serve files as they are
